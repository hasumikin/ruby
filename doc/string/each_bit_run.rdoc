Calls the given block with each run of equal bits of +self+; returns +self+.
A run is a maximal sequence of consecutive bits with the same value. For each
run, the block receives the bit (+0+ or +1+), the zero-based offset of its
first bit, and its length, in increasing order of offset:

  data = "\x0F\x01"
  data.each_bit_run {|bit, offset, length| p [bit, offset, length] }
  # Output:
  #   [1, 0, 4]
  #   [0, 4, 4]
  #   [1, 8, 1]
  #   [0, 9, 7]

With no arguments, scans all bits of +self+. With +offset+ and +length+,
scans only the +length+ bits beginning at zero-based bit +offset+; with a
Range, scans the bits covered by +range+. The runs are cut at the region
boundaries: the first run starts at the region start even if the same bit
continues before it, and the last run ends at the region end. The yielded
offsets are always relative to the start of +self+:

  data.each_bit_run(2, 8).to_a # => [[1, 2, 2], [0, 4, 4], [1, 8, 1], [0, 9, 1]]
  data.each_bit_run(8..).to_a  # => [[1, 8, 1], [0, 9, 7]]

A region that extends beyond the end of +self+ is clamped to the bits that
exist; a region that begins at or beyond the end yields nothing.

By default, bits within each byte are numbered from least-significant to
most-significant. If +lsb_first+ is +false+, byte order is unchanged but bits
within each byte are numbered from most-significant to least-significant:

  "\x0F".each_bit_run(lsb_first: false).to_a # => [[0, 0, 4], [1, 4, 4]]

With no block given, returns a new Enumerator whose +size+ is the number of
runs in the region:

  data.each_bit_run.size # => 4

The block may modify +self+. The iteration reads the current contents of
+self+ for each run and stops at the current end of +self+.

Raises +ArgumentError+ if +offset+ is given without +length+.
Raises +IndexError+ if +offset+ or a Range endpoint is negative.
Raises +ArgumentError+ if +length+ is negative.
Raises +ArgumentError+ if a bit position is too large to be represented.
Raises +ArgumentError+ if +lsb_first+ is neither +true+ nor +false+.
